# AGENTS.md

Codex と Claude Code に共通する個人用指示。リポジトリ固有の規約を優先する。

## 判断と参照

- 実装・レビューで設計判断が必要なときは `~/.agents/principles.md` を読む。
- 調査報告、PR本文、外部共有する文書を書くときは `~/.agents/writing.md` を読む。
- 図、成果物の清書、外部サービス、固有CLIは、作業に必要なときだけ該当Skillを使う。

## 作業の境界

- 本番DBにはAIを接続しない。必要な確認は安全な管理API、テレメトリ、コード調査、または人が実行できる手順で行う。
- 削除、force push、本番反映、外部送信、投稿、購入、課金を伴う操作は、対象と影響を確認してから実行する。
- 未コミットの変更とユーザーの作業中ファイルを保護する。関連しない変更は加えない。
- 仕様変更は、調査、対応方針の承認、基本設計の承認を経て実装する。調査のみ、レビューのみ、小さく安全な修正は目的に必要な範囲で直接進めてよい。
